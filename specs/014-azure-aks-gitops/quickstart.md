Target interfaces, not existing execution evidence. Run at repository root;
Windows uses npm.cmd.

1. Install checksum-verified locked tools privately; `npm run infra:check` must run
   without cloud credentials. Real negative fixtures fail formatting/config/lint/
   security and missing-scanner/policy cases identically locally/CI.
2. Supply restricted config, `npm run infra:preflight -- --config PATH`; validate
   supported patch/quota/tenant permissions/operator identity/CIDR and fixed EUR120
   tax-inclusive BOM using actual supplied taxRate, including protected audit costs,
   before paid provisioning. No insecure default configuration.
3. Bootstrap retained foundation with human identity, migrate state to Blob and
   verify remote authority. Configure protected GitHub environments/OIDC/roles;
   validate retained recovery vault/key and separate wrap/unwrap roles. Owner delegates nameservers and
   accepts ACME terms/contact. Check authoritative DNS before issuance.
4. Review private immutable-revision plan, apply locally through shared commands,
   populate secrets outside TF, generate concrete allowlisted runtime configuration
   and merge its reviewed Git change. Protected `npm run infra:bootstrap -- --config
   PATH --revision SHA` must match generation/output hash before Argo/readiness.
   An infrastructure-applied/configuration-review-pending phase is not environment
   success. Validate all four HTTPS
   endpoints, login, operator assignment and negative anonymous/unauthorized/source
   denial. Run six deployed journeys through private diagnostic forwards; verify
   no internal endpoint public exposure and actual secret rotation behavior.
5. Record booking/user with existing persistence CLI; replace app/data pods, stop,
   wait required settling interval, start. Prove certificate/CSI/login/booking/broker
   and historical telemetry survive. Inspect actual correlated signals, labels,
   memory/storage pressure and72h bounds; distinguish configured from elapsed evidence.
6. Prove one source-proven component artifact is published to GHCR and ACR with matching
   remote digests; partial failure blocks promotion and retries do not rebuild.
   Exercise reviewed digest release/drift correction/protected deletion independently
   of TF. Test seasonal stop schedules, override expiry, actual scheduled stop and
   missed-run diagnostics; stopped backup does not start compute.
7. Check reviewed deny-sync window (or explicit reviewed restore maintenance SHA),
   exact scale-only/client-exec RBAC and fail-closed isolated Job admission policy.
   Drain/quiesce, encrypt full backup and verify by isolated restore. Record point,
   compatibility and retained inventory. Review confirmed approved workload destroy;
   original workload/disks removed, foundation intact.
8. Recreate using GitHub protected reviewed revision/OIDC. Verify stale-plan/fork/
   unauthorized operations blocked and runner /32 cleaned. Kill an admitted owner
   abruptly and prove independent expiry reaper, failed-reaper diagnostics and next
   operation fail-closed baseline reconciliation. Fresh installation passes
   acceptance before any data restoration.
9. Explicit approved restore uses retained-key unwrap authority, checks compatibility/hashes,
   suspends writers/reseed, restores and verifies original login/booking/messaging.
   Record elapsed session. Missing drain/verified backup or incompatibility blocks.
10. Save exact revision/command/environment/outcome evidence. Run required format,
    lint, tooling, actual TF gates, render/schema/workflow checks; independent reviews,
    convergence and explicit human acceptance remain mandatory. Pending live/hosted/
    browser checks remain pending, never replaced by static fixture results.

Also exercise actual authorized/denied Blob Read/Write/Delete on both retained
accounts, verify protected transformed audit rows and unauthorized-reader denial,
and inspect forbidden fields, retention/quota and budget. No raw audit export or
Queue-only workaround. Eleven scoped exceptions remain limited to their approved
rule/resource addresses; SEC-TF001 and actual Blob auditing are not waived.

break-glass credential and localhost forward, rotate after use. No unauthenticated
public bypass. Verify retained key/version and unwrap authority before destruction;
lost/deleted recovery key means encrypted recovery cannot succeed.
